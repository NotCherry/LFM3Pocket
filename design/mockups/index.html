Phase 1 · static mockups

Three ways to hold a local model.

LFM3 Pocket is an Android chat for Liquid AI’s LFM3 models. Inference stays on the phone. These renders use the real screens — home, chat, empty, generating, settings, history — and the real copy around models, search, photos, and tool consent. Nothing in the app is restyled yet. Open a direction, then pick one for the rebuild.

Stillwater

Dark and quiet, like a private notebook. Serif wordmark, open text with a warm rule instead of chat bubbles, one candle accent, and settings as rows with steppers. The camera is a full-bleed viewfinder, not another text button.

Field

Light-first, so it holds up outdoors, with the same conversation shown in the dark. Clear user bubbles, a small liquid mark on LFM3’s replies, photos in the thread, and the loaded Omni model as one status. Deep green, not a purple gradient.

Keel

A pocket instrument. Home is a readout — model, context 4096, four threads, search off — and chat keeps prose separate from mono metadata. Flashlight consent is an explicit Approve / Reject sheet with the real tool name and arguments.
